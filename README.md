# Coffees Medy ☕

Coffees Medy es un sistema web orientado a la gestión de una cafetería, desarrollado como proyecto académico.

El sistema integra diferentes funcionalidades relacionadas con la visualización de productos, pedidos, compras, usuarios, administración y gestión de información mediante una base de datos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- SQL Server

## Estructura general

El proyecto se encuentra organizado en diferentes módulos que serán incorporados progresivamente al repositorio durante el desarrollo.

Entre ellos se encuentran:

- Página principal
- Catálogo de productos
- Bebidas calientes
- Frappés
- Descuentos
- Pedidos
- Pagos
- Vouchers
- Usuarios
- Delivery
- Registro de productos
- Registro de repartidores
- Base de datos
- Backend con Node.js y Express
